# WorkBuddy 场景海报与文案

8 个岗位场景各一套：海报两版（`posters/xhs/`、`posters/wechat/`）+ 小红书笔记 + 群/朋友圈短文案。海报用 `node scripts/render-scene-posters.mjs` 从 `miniprogram/services/scenes.ts` 重新生成；改了必装技能后，海报要重新生成，这份文案也要同步改。

## 发布前须知

- **小红书不要引流到微信**：海报 xhs 版和笔记正文都不提小程序、不放二维码、不写「微信搜索」。平台会对站外引流限流甚至处罚。笔记本身要把东西给全：3 个技能干什么、怎么说，安装指令放在置顶评论。
- **群 / 朋友圈**用 wechat 版海报和短文案。把各场景的小程序码放到 `docs/marketing/qr/<场景>.png`（例如 `finance.png`）再重新生成，海报右下角就会带上码；没有码时只显示「微信搜索」。
- **不夸效果**：这些技能还没在 WorkBuddy 里实测，文案只说它们「能做什么」，不写「10 秒搞定」「效率翻倍」这类承诺。哪天实测了，可以把真实截图加进笔记，转化会好很多。
- 每篇都注明「技能来自 GitHub 开源项目，非 WorkBuddy 官方」，避免被当成冒用官方。
